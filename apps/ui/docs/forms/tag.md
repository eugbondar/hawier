# The tag form

> A name, and optionally a colour.

## The form {#the-form}

Creates a label. Creating it attaches it to nothing — apply it from a device or distribution set page, or to a selection of rows.

## Name {#name}

What the tag is called, and what you will type in a query: `tag==canary`.

Keep them short and consistent. Tag names are matched exactly, so `Canary` and `canary` are two different tags.

## Description {#description}

Free text. Worth using to record what the tag is **for** — a tag whose meaning nobody remembers stops being useful.

## Colour {#colour}

Makes the tag findable at a glance on a crowded page. It has no other effect.
