# The software module form

> The container. The files come after.

## The form {#the-form}

Creates a module with no [artifacts](/help/repository/artifacts#artifacts) in it. Upload the files on the module's page afterwards — until then it is a module that would give a device nothing to download.

## Name {#name}

What the software is called. With the version, this identifies the module.

## Version {#version}

The version of this module. Name and version together are the identity, so two versions are two modules and both can exist at once.

## Type {#type}

Which [module type](/help/repository/sm-types#software-module-types) this is — operating system, application, firmware. This is what a distribution set type refers to when it demands that a set contain an operating system.

## Vendor {#vendor}

Who produced it. Free text, recorded and searchable, used for nothing else.

## Description {#description}

Free text. What this module is and what changed in this version.
