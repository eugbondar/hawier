# Search

> One box across the whole repository.

## Global search {#global-search}

The box in the top bar searches targets, rollouts, distribution sets, software modules and tags in one request, and groups the results by kind. **Ctrl+K** focuses it from anywhere.

The text you type is matched as a fragment: `prod` finds `prod-gateway-04`. Characters that mean something to the query language are escaped for you, so you can type freely.

## Recent searches {#recent}

An empty search box offers what you searched for recently. Each entry can be forgotten individually, or the whole history cleared.

## Searching a single list {#list-search}

Global search is deliberately shallow — it finds objects by name. To ask a precise question about one kind of object, open its list and use **Filters** with a [query](/help/reference/rsql#the-query-language).
