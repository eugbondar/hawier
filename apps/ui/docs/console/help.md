# Help

> How the console explains itself.

## The manual {#the-manual}

Every screen, field, column and status word in this console is documented, and the documentation is part of the console — it ships in the same binary and always matches the build you are looking at.

There are two ways in. **Help** in the navigation column opens this manual at its table of contents. The **question mark** in the top bar answers a question about one specific control without taking you off the page.

## What's This? {#whats-this}

Press the question mark in the top bar — or **Shift+F1** — and the pointer turns into a question mark. Click anything on the page and a panel opens on the right with the answer for that control, plus a link to the full article.

The click that asks the question does nothing else: it does not open the row, submit the form or run the operation you clicked. After it answers, help mode switches itself off. Hold **Ctrl** while clicking to stay in help mode and keep probing.

While help mode is armed, anything that has an answer outlines when you hover over it. If you click somewhere with no answer of its own, you get the article for the page you are on.

**Esc** leaves help mode, or closes the panel once it is open.

## Reading a page without help mode {#without-javascript}

The manual is ordinary linked pages. If scripting is off, the question mark in the top bar is a plain link to the table of contents, and every article is reachable from there.
