# Extension surfaces

> Lists contributed at runtime by an extension.

## Declared by an extension {#declared-by-an-extension}

This list did not ship with the console: an extension running on this node declared it, and the console adopted it at startup. Its columns, its filters and its views come from that extension and from the server's field map, so the manual cannot describe them the way it describes the built-in lists.

It behaves like every other list: the same filters, the same sorting, the same paging, the same selection and the same saved views. What it contains is a question for whoever installed the extension.

Built-in lists always win a name collision, so an extension can add a list but never replace one.
