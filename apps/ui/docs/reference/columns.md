# Columns

> What the columns of a list are, and what to do when one is not explained.

## An undocumented column {#an-undocumented-column}

This column has no entry of its own in the manual yet. It is a field the server returned for this object; the **raw** switch on the object page shows its exact value, and that value is what a query takes.

If the column belongs to a list contributed by an extension, the console never knew about it — see [extension surfaces](/help/console/surfaces#declared-by-an-extension).

## Choosing columns {#choosing}

**Filters** on any list opens the column chooser. The choice is part of the view, so it can differ between two views of the same list.

## Sorting {#sorting}

Every column header sorts. Click for ascending, click again for descending. A field the server cannot sort by answers with an error rather than a silently unsorted list — see [sorting](/help/reference/sorting#sort-orders).
