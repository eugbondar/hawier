# Distribution set tags

> Labels on distribution sets, the same idea as tags on devices.

## Tags {#tags}

A tag is a name, an optional description and an optional colour, attached to any number of distribution sets. Use them to mark releases: `stable`, `beta`, `recalled`, `2026-q3`.

Tagging a set changes nothing about it — no device is affected, nothing is installed or cancelled.

## Using them {#using}

`tag==stable` in a filter on the distribution set list selects everything carrying that tag. Tags can be added to and removed from a selection of rows through the operations menu.

Deleting a tag removes it from every set that carried it and leaves the sets alone.

## All {#all}

Every distribution set tag in the tenant.
